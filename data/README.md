# Dataset

Source: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Publisher: Olist and collaborators. Real, anonymised marketplace records from
2016–2018. Review text has been anonymised by the publisher; it is not used in
this project.

Dataset licence: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
Credit the publisher, retain the noncommercial/share-alike terms, and link back
to the source. Original CSVs in the complete download are unmodified. Adapted
data tables and charts in this project retain the same data licence. No Olist
affiliation or endorsement is claimed.

The public GitHub-ready package omits raw files. Download the dataset from the
source page, extract it and place these nine files directly in `data/raw/`:

- `olist_orders_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_order_payments_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `olist_geolocation_dataset.csv`
- `product_category_name_translation.csv`

The complete local package already contains them. Do not add an extra nested
`archive/` folder between `data/raw/` and the CSVs.

`outputs/tables/source_manifest.csv` records byte sizes and SHA-256 hashes of the
supplied files. File-level counts and missingness are generated by Python,
rather than assumed from the source's rounded description.

See `docs/DATA_DICTIONARY.md` for fields and `docs/DATA_NOTES.md` for metric
definitions and cleaning choices. `data/raw/*.csv` is excluded from Git tracking.
